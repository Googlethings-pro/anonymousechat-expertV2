# Daftar Command (Fitur) Bot Anonymouse Chat

Berikut adalah ringkasan lengkap semua perintah (command) yang tersedia di dalam bot, beserta fungsinya:

## 👥 Command Umum (Untuk Semua Pengguna)

- `/start` - Menyalakan bot, menampilkan pesan sapaan, atau mendaftar ke bot untuk pertama kali.
- `/menu` - Membuka menu utama yang berisi tombol-tombol navigasi bot.
- `/search` - Memulai antrean pencarian untuk menemukan partner ngobrol secara acak.
- `/next` - Menghentikan obrolan dengan partner saat ini dan langsung mencari partner ngobrol baru secara otomatis.
- `/stop` - Menghentikan obrolan atau keluar dari antrean pencarian dan kembali ke menu utama.
- `/settings` - Membuka menu pengaturan bot (mengubah preferensi bahasa, filter gender, atau region).
- `/link` - Menampilkan link bot dan link referral Anda untuk mengundang teman.
- `/rules` - Menampilkan aturan, larangan, dan panduan penggunaan bot.
- `/reaction` - Mengirim atau mengatur reaksi (emoji) terhadap interaksi di obrolan.
- `/vip` / `/pay` / `/premium` - Menampilkan informasi tentang keuntungan VIP dan menu untuk berlangganan / upgrade ke VIP Premium.


---

## 👑 Command Khusus [ADMIN / OWNER]

- `/server` **[ADMIN]** - Mengecek status VPS / Server tempat bot berjalan (menampilkan pemakaian CPU, RAM, Ping, dll).
- `/broadcast <pesan>` **[ADMIN]** - Mengirim pesan siaran (pengumuman massal) ke seluruh pengguna bot yang terdaftar di database.
- `/ban <ID_User>` **[ADMIN]** - Melarang atau memblokir (*banned*) pengguna agar tidak bisa menggunakan bot ini selamanya.
- `/unban <ID_User>` **[ADMIN]** - Membuka blokir pengguna yang sebelumnya telah di-ban agar bisa menggunakan bot kembali.
- `/unprem <ID_User>` **[ADMIN]** - Menghapus status keanggotaan VIP / Premium dari seorang pengguna secara manual.
